Wallspace for Windows

一款轻量、现代的 AI 桌面壁纸应用。输入提示词生成专属壁纸，一键应用到显示器，支持画廊管理、多显示器、深色浅色主题。

应用预览

简洁现代的界面，从发现到设为壁纸只需几步。

核心功能

围绕「生成 → 管理 → 应用」打造的完整壁纸工作流。

✨

AI 生图

支持 OpenAI 兼容接口与 Grok 直连，b64 / URL 双回退，配置 API 即可一键生成。

🖥️

多显示器支持

按目标显示器分辨率智能裁剪，可为每个屏幕单独设置壁纸，或一键应用到全部。

🖼️

画廊管理

生成、链接下载、本地导入统一入库；支持重命名、分类、收藏、删除、Ctrl+K 搜索。

🌓

深色 / 浅色主题

跟随系统或手动切换，窗口 Acrylic 底色随主题联动，沉浸感更佳。

📥

本地导入与链接下载

支持文件选择器、全窗口拖放导入，或粘贴图片直链下载入库，离线可用。

⌨️

快捷键

Ctrl+K 搜索、Ctrl+B 侧栏、Esc 关闭预览、F 收藏，操作更顺手。
